library(tidyverse)
dat <- read.csv("resource_0.csv", 
                header = TRUE)
#str(dat)
dat_fig <- dat %>% select(c(AREA_NAME, ASSAULT_RATE_2024))

names(dat_fig) <- c("AREA", "2024")
#str(dat_fig)

#names(dat_fig$AREA)

dat_fig <- dat_fig %>%
  arrange(desc(`2024`)) %>%
  slice_head(n = 7)

#print (dat_fig)
#str(dat_fig)
dat_fig$`2024` <- round(dat_fig$`2024`)
#print (dat_fig)

dat_fig$AREA <- as.factor(dat_fig$AREA)
#str(dat_fig)
dat_fig$AREA <- as.factor(dat_fig$AREA)
#str(dat_fig)
ggplot(dat_fig, aes(x = AREA, y = `2024`, fill = AREA)) +
  geom_bar(stat = "identity", width = 1) + 
  theme_minimal() +
  theme(
    axis.text.x = element_blank(), #remove x axis labels
    axis.text.y = element_blank(),  # Remove y-axis labels
    axis.ticks = element_blank(),   # Remove ticks
    panel.grid = element_blank(),    # Remove grid lines
    legend.title = element_text(size = 10, face = "bold",
                                family = "sans"),  # Customize legend title
    legend.text = element_text(size = 8,
                               family = "sans")  # Customize legend text,
    
  ) +
  
  labs (x = "",
        y = "",
        #title = "(Relatively) Dangerous Toronto Neighborhoods",
        fill = "(Relatively) Dangerous\nToronto Neighborhoods") +
  scale_fill_brewer(palette = "Set2") +
  coord_polar(theta = "x", start = 0, direction = -1) +
  geom_text(aes(y = `2024`, label = `2024`),
            color = "black")

The data was obtained using the API provided by the City of Toronto’s Open Data portal. It was retrieved using a Python script used in the first part of this assignment. The retrieved data was placed in the file resource_0.csv and this is the file being used in this analysis.

The audience comprises anyone interested in Assault rates in Toronto including journalists, law enforcement officers, researchers, and others.

This plot identifies the 7 (out of 158) neighborhoods in Toronto with the maximum number of Assault incidents in 2024 through the usage of a Coxcomb plot.

The visual layout makes the plot aesthetically appealing. The simplicity of the plot makes it perceptual although note the complexities in this plot: the plot tells us the rate of Assaults in 2024 where rate is defined as the number of assaults per 100,000 people (this is the number label seen on each wedge), and the size of each wedge in the plot corresponds to its rate value.
